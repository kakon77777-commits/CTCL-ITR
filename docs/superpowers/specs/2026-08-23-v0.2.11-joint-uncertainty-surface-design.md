# CTCL-ITR v0.2.11 — Joint Sampling × Mixture Sensitivity Surface Design

**Date:** 2026-08-23

## Goal

Extend v0.2.9 outcome-sampling uncertainty and v0.2.10 reference-mixture sensitivity into one joint diagnostic surface. Each legal reference-mixture cell is evaluated under the same deterministic set of resampled outcome evidence, so the runtime can report how drift bands, sign stability, and support change across mixture choice without treating mixture cells as independent random experiments.

## Core boundary

```text
Joint Surface != Causal Truth
Surface Cell != Independent Experiment
Sign-Stable Region != Guaranteed Improvement
Unsupported Region != Negative Drift
Joint Uncertainty Surface != Authority
```

The release is observational and non-authoritative. It cannot grant, revoke, suspend, resume, or commit actions.

## Architecture

Inputs remain the existing raw v0.2.8 snapshot specifications, one v0.2.8 comparison specification, and a new v0.2.11 joint-surface specification. The analyzer:

1. builds the original point-estimate snapshots;
2. enumerates the inherited v0.2.10 bounded simplex reference-mixture grid;
3. computes one point estimate at every grid cell with v0.2.8 comparison semantics;
4. for each replicate, resamples base/current success counts once using the v0.2.9 deterministic empirical-binomial method;
5. builds the resampled snapshots once per replicate;
6. evaluates every mixture cell against those same resampled snapshots;
7. summarizes each cell with supported replicate count/rate, percentile band, mean, sign shares, unsupported reasons, and band-sign class;
8. summarizes the whole subject surface with support-region and sign-region counts.

This preserves cross-cell dependence within each replicate and avoids pretending that nine mixture cells are nine independent bootstraps.

## Method contract

Reference method identifier:

```text
joint_empirical_binomial_simplex_surface_v1
```

The v0.2.11 spec embeds two existing contracts:

- resampling: `stratified_empirical_binomial_sha256_v1`;
- mixture grid: `simplex_grid_reference_mixture_v1`.

The canonical release uses 256 replicates, a 90% percentile band, minimum supported fraction 0.5, grid step 0.1, and minimum family weight 0.1.

## Surface cell

For each subject and reference-mixture cell:

```text
reference_family_weights
point_estimate
point_support_status
point_support_reasons
supported_replicates
total_replicates
supported_fraction
resampling_support_status
band
mean
sign_shares
band_sign_class
unsupported_reason_counts
```

`band_sign_class` is one of:

```text
positive_band
negative_band
crosses_zero
zero_band
unsupported
```

It is derived only when the resampling band itself is supported.

## Subject surface summary

The report records:

- total mixture cells;
- point-supported cells;
- resampling-supported cells;
- resampling-supported fraction;
- counts for each band-sign class;
- whether sign classification is mixture-sensitive;
- minimum/maximum supported fraction across cells;
- minimum/maximum band width across supported cells;
- unsupported-reason totals.

No scalar `total_uncertainty` is produced.

## Support discipline

All support/no-extrapolation behavior comes from v0.2.7/v0.2.8/v0.2.10. A replicate-cell can be unsupported because its resampled family curves do not bracket the target reliability or lack common depth support. Unsupported cells are counted, not imputed.

The v0.2.11 `minimum_supported_fraction` controls whether a percentile band is emitted for a cell. A low supported fraction never silently becomes a band.

## Determinism

The same seed, evidence, mixture grid, and method contract must regenerate byte-equivalent JSON values. Replicate `r` uses the same resampled base/current evidence for every mixture cell. Changing the mixture does not change random draws.

## Compatibility

- v0.2.10 sensitivity semantics unchanged;
- v0.2.9 resampling semantics unchanged;
- v0.2.8 comparison semantics unchanged;
- v0.2.7 calibration method unchanged;
- governance/runtime contracts unchanged;
- no new runtime dependency.

## Non-goals

v0.2.11 does not:

- estimate causal backend effects;
- resample task-family composition;
- claim Bayesian posterior probabilities;
- guarantee confidence-interval coverage;
- interpolate over unsupported mixture cells;
- create automatic governance actions.
