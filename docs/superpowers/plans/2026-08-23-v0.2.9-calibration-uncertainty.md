# Calibration Uncertainty & Drift Bands Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build deterministic stratified empirical-binomial resampling above v0.2.8 and emit auditable Horizon/drift bands.

**Architecture:** New `ctcl_itr.calibration_uncertainty` consumes already-calibrated v0.2.8 snapshots plus the v0.2.8 comparison spec. It reconstructs family evidence counts from snapshot profiles, generates deterministic resampled counts, reruns existing calibration/robustness code, and summarizes only supported replicates. No existing calibration or governance semantics are mutated.

**Tech Stack:** Python stdlib, SHA-256, existing CTCL-ITR v0.2.7/v0.2.8 APIs, JSON Schema Draft 2020-12, pytest.

**Spec:** `docs/superpowers/specs/2026-08-23-v0.2.9-calibration-uncertainty-design.md`

## Global Constraints
- Preserve all v0.2.8 public behavior.
- No new runtime dependency.
- No Horizon extrapolation.
- Fixed task-family weights during resampling.
- Deterministic output for identical inputs + seed.
- Unsupported replicates are explicit and never silently imputed.
- Resampling diagnostics are non-authoritative.
