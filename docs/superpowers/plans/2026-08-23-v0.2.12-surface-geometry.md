# CTCL-ITR v0.2.12 Surface Geometry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add deterministic, evidence-supported geometry over v0.2.11 joint uncertainty surfaces without interpolating unsupported regions.

**Architecture:** A new read-only `calibration_surface_geometry` analyzer consumes the v0.2.11 surface report and a small geometry spec. It constructs the simplex adjacency graph, extracts supported/sign-region components and boundary edges, interpolates only zero crossings between adjacent supported cells, and computes edge-local slopes.

**Tech Stack:** Python 3.11+, standard library, JSON Schema Draft 2020-12, pytest.

**Spec:** `docs/superpowers/specs/2026-08-23-v0.2.12-surface-geometry-design.md`

## Global Constraints

- Preserve v0.2.11 joint-surface semantics and all earlier runtime contracts.
- No new runtime dependency.
- Never interpolate across an unsupported cell or support-boundary edge.
- Surface geometry is non-authoritative and non-causal.
- Use deterministic ordering and no hidden randomization.
- Canonical source remains the downloadable release pack when connector transport limits prevent large reference files in GitHub.
