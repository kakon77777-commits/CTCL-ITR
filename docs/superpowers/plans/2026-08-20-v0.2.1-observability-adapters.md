# CTCL-ITR v0.2.1 Observability Adapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add lossless CloudEvents 1.0 envelopes and deterministic OpenTelemetry-style span projections for ATL ledgers.

**Architecture:** Keep ATL events canonical and implement pure projection functions in `ctcl_itr.interop`. CloudEvents carries the full ATL event under `data`; OpenTelemetry projection preserves single-parent edges as parent spans and multi-parent joins as span links.

**Tech Stack:** Python 3.11+, stdlib, pytest, jsonschema (existing pack validation only).

**Spec:** `docs/superpowers/specs/2026-08-20-v0.2.1-observability-adapters-design.md`

## Global Constraints

- No OpenTelemetry SDK dependency in v0.2.1.
- No CloudEvents SDK dependency in v0.2.1.
- ATL `causal_parent_ids[]` remains canonical causality.
- Multi-parent Join must never be silently collapsed to one parent.
- Full ATL event must round-trip through the CloudEvents reference envelope.
- Existing v0.1 and v0.2 tests must stay green.
