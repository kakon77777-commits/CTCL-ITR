# CTCL-ITR v0.2.11 Joint Sampling × Mixture Sensitivity Surface Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a deterministic joint surface that evaluates outcome-resampling uncertainty at every supported v0.2.10 reference-mixture cell.

**Architecture:** Add one public facade/CLI and one focused internal engine. Reuse v0.2.9 deterministic resampling, v0.2.10 simplex grid generation, and v0.2.8 comparison semantics; do not duplicate Horizon logic. Every replicate resamples evidence once and reuses that replicate across all mixture cells.

**Tech Stack:** Python 3.11+, standard library, existing jsonschema test dependency, pytest.

**Spec:** `docs/superpowers/specs/2026-08-23-v0.2.11-joint-uncertainty-surface-design.md`

## Global Constraints

- No new runtime dependency.
- No TemporalEvent or governance authorization schema changes.
- No mixture-cell extrapolation.
- No scalar additive total uncertainty.
- Same seeded inputs must reproduce the same report.
- Surface remains non-authoritative.
