# CTCL-ITR v0.2.10 Reference-Mixture Sensitivity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Add deterministic reference-mixture sensitivity scanning and keep it as a separate uncertainty axis from v0.2.9 outcome-sampling bands.

**Architecture:** A dependency-free `calibration_mixture_sensitivity` module enumerates a bounded simplex grid and delegates every point to the existing v0.2.8 comparison engine. An optional v0.2.9 uncertainty report is identity-checked and summarized alongside, never arithmetically merged into a synthetic total uncertainty.

**Tech Stack:** Python standard library, JSON Schema Draft 2020-12, pytest.

**Spec:** `docs/superpowers/specs/2026-08-23-v0.2.10-reference-mixture-sensitivity-design.md`

## Global Constraints

- Preserve v0.2.8 comparison semantics and no-extrapolation support rules.
- Preserve v0.2.9 resampling semantics unchanged.
- No new runtime dependency.
- No authority mutation.
- Sensitivity and sampling uncertainty remain separate axes.
