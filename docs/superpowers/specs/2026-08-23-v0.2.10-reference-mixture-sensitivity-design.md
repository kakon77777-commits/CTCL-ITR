# CTCL-ITR v0.2.10 — Reference-Mixture Sensitivity & Uncertainty Decomposition Design

## Goal

Extend v0.2.9 with a read-only sensitivity layer that varies the v0.2.8 fixed reference task-family composition and keeps that sensitivity separate from v0.2.9 outcome-sampling uncertainty.

## Core boundary

```text
Sampling uncertainty != reference-mixture sensitivity
Reference-mixture sensitivity != composition drift
Sensitivity span != causal effect
Uncertainty axes != additive total uncertainty
Sensitivity report != authority
```

The release reports a vector of uncertainty/sensitivity axes rather than claiming:

$$
U_{total}=U_{sampling}+U_{mixture}.
$$

The reference representation is instead:

$$
\mathbf U_s=(W^{sampling}_s,\;S^{mixture}_s),
$$

where $W^{sampling}_s$ is the v0.2.9 percentile-band width at the declared reference mixture and $S^{mixture}_s$ is the supported range of v0.2.8 composition-adjusted drift under a declared simplex grid.

## Inputs

The analyzer consumes:

- v0.2.8 calibrated base snapshot;
- v0.2.8 calibrated current snapshot;
- v0.2.8 comparison spec containing the declared reference mixture;
- v0.2.10 sensitivity spec;
- optional v0.2.9 uncertainty report for the same base/current/comparison identity.

It does not mutate any input.

## Sensitivity contract

Reference method identifier:

```text
simplex_grid_reference_mixture_v1
```

The sensitivity spec declares:

- `grid_step`;
- `minimum_family_weight`;
- `max_grid_points`;
- deterministic family ordering from the compared family IDs.

Both `grid_step` and `minimum_family_weight` must be exact integer multiples of the simplex unit within floating tolerance, and the grid must be able to allocate the required minimum to every family.

The generator enumerates all positive family-weight vectors on the declared grid whose weights sum to one. It refuses a grid larger than `max_grid_points`.

## Per-grid evaluation

For every reference mixture $w$ the analyzer creates a temporary v0.2.8 comparison spec and reuses `compare_calibration_snapshots()`.

No family curve is extrapolated. Existing v0.2.8 support rules remain canonical. Unsupported mixtures remain explicit and contribute to `unsupported_reason_counts` rather than being imputed.

For each subject (`autonomy`, `governance`) the report records:

- reference point estimate at the originally declared v0.2.8 mixture;
- every scanned mixture and support status;
- supported / total grid point counts and fraction;
- minimum and maximum supported adjusted drift;
- mixture-choice sensitivity span;
- argmin / argmax mixture weights;
- positive / negative / zero shares across supported mixtures;
- reference point position inside the supported sensitivity range;
- unsupported reason counts.

## Sampling uncertainty bridge

If a v0.2.9 uncertainty report is supplied, it must match:

- base snapshot ID;
- current snapshot ID;
- comparison ID;
- measurement contract;
- reference mixture.

The analyzer extracts only the `composition_adjusted_delta` sampling band at that reference mixture.

For each subject it reports:

```text
sampling_band_width_at_reference
reference_mixture_sensitivity_span
mixture_to_sampling_width_ratio
```

and a purely descriptive `larger_reported_axis` label (`sampling`, `mixture_choice`, `equal`, or `unavailable`). This label does not establish which uncertainty source is scientifically dominant outside the declared contracts.

## Canonical reference

Use the existing two-family v0.2.8 reference case and scan:

```text
families = [code, research]
grid_step = 0.1
minimum_family_weight = 0.1
```

This yields nine candidate mixtures from 10/90 through 90/10. Mixtures that violate the existing support/bracketing discipline are reported as unsupported.

The canonical report must demonstrate:

- supported adjusted drift remains positive across supported mixtures;
- some extreme mixtures are unsupported rather than extrapolated;
- sampling-band width and reference-mixture sensitivity span remain separate axes;
- no scalar total uncertainty is emitted.

## Non-goals

v0.2.10 does not:

- resample outcome counts (v0.2.9 owns that axis);
- model a probability distribution over reference mixtures;
- choose an ethically or scientifically privileged benchmark composition;
- claim a causal backend effect;
- combine axes into a confidence interval;
- grant/revoke authority or trigger enforcement.
