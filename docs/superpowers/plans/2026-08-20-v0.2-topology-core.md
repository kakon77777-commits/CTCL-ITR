# CTCL-ITR v0.2 Topology Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build and validate a runtime-neutral causal topology analyzer for ATL ledgers with branch/join detection, work/depth metrics, critical path, and exact finite-poset width.

**Architecture:** Keep ATL JSONL as canonical input and implement a pure dependency-free Python analyzer under `src/ctcl_itr/topology.py`. Extend the v0.1 event schema only with optional branch/join metadata, add a three-branch reference ledger, and expose JSON CLI output without mutating event history.

**Tech Stack:** Python 3.11+, stdlib, pytest 8.x, jsonschema 4.x, JSON Schema Draft 2020-12.

**Spec:** `docs/superpowers/specs/2026-08-20-topology-core-design.md`

## Global Constraints

- Existing v0.1 ledgers MUST remain schema-valid.
- `causal_parent_ids[]` remains the canonical hard happens-before relation.
- Analyzer MUST NOT depend on private chain-of-thought or executor internals.
- Analyzer MUST NOT mutate ledger events.
- Unsupported or invalid topology MUST fail explicitly.
- Production code is written only after a corresponding failing test has been observed.
