# CTCL-ITR v0.2.12 — Surface Geometry & Stability Boundaries Design

**Date:** 2026-08-23

## Purpose

v0.2.11 produces a discrete joint uncertainty surface over reference-mixture cells. v0.2.12 adds a geometry layer that summarizes only evidence-supported discrete structure: supported-region connectivity, sign-stability regions, support boundaries, conservative sign-boundary interpolation, and local edge gradients.

The geometry layer is diagnostic only.

```text
Surface Geometry != Causal Geometry
Interpolated Boundary != Observed Cell
Unsupported Region != Negative Region
Local Gradient != Global Derivative
Geometry Report != Authority
```

## Source Contract

Input is a v0.2.11 `CalibrationJointSurfaceReport` plus a v0.2.12 geometry spec.

The source surface must declare:

- `schema_version = 0.2.11`;
- `method = joint_empirical_binomial_simplex_surface_v1`;
- at least two task families;
- a positive `mixture_grid.grid_step`;
- one cell list for `autonomy` and `governance`;
- each cell with `reference_family_weights`, point estimate, resampling support state, band, and `band_sign_class`.

No new sampling, Horizon fitting, or mixture construction occurs in v0.2.12.

## Simplex Adjacency

Let the declared grid step be `h`. Two mixture cells are adjacent iff one grid step is transferred from one family to another:

$$
\sum_f |w_f^{(i)}-w_f^{(j)}| = 2h
$$

and exactly one family increases by `h`, exactly one decreases by `h`, with all other coordinates unchanged within the declared tolerance.

This defines the discrete simplex graph. It works for two or more task families.

## Supported Graph

A cell is geometry-supported only when:

```text
cell.resampling.support_status == "supported"
```

The supported graph contains only supported cells and adjacency edges between supported cells.

The analyzer reports:

- supported node count;
- supported edge count;
- connected components;
- isolated supported cells;
- component sizes and member composition keys.

Unsupported cells are never used to connect supported components.

## Sign Regions

Within the supported graph, cells retain the v0.2.11 band classes:

- `positive_band`;
- `negative_band`;
- `crosses_zero`;
- `zero_band`.

For each class, v0.2.12 computes connected components using only same-class supported adjacency edges.

This is discrete region topology. It does not claim a continuous sign region between observed cells.

## Boundaries

### Support boundary

A support-boundary edge is an adjacent pair with exactly one resampling-supported endpoint.

No interpolation is performed across such an edge.

### Sign-class boundary

A sign-class boundary is an adjacent supported pair whose `band_sign_class` differs.

### Conservative positive-stability boundary

A positive-stable cell has a resampling band lower endpoint above zero. Between two adjacent supported cells, a positive-stability boundary point may be interpolated only when their lower endpoints bracket zero (with tolerance):

$$
L(t) = (1-t)L_0+tL_1 = 0,\quad 0\le t\le1.
$$

The composition is interpolated along the same supported adjacency edge:

$$
w(t)=(1-t)w_0+tw_1.
$$

This estimates the local `lower-band = 0` crossing. It is not an observed evidence cell.

### Conservative negative-stability boundary

Analogously, negative stability uses the upper band endpoint and interpolates only when adjacent supported endpoints bracket `upper-band = 0`.

## Local Gradients

For each adjacent supported pair with finite point estimates, let transferred mass be:

$$
m_{ij}=\frac12\sum_f |w_f^{(i)}-w_f^{(j)}|.
$$

The local point-estimate slope is:

$$
g_{ij}^{\Delta H}=\frac{\Delta H_j-\Delta H_i}{m_{ij}}.
$$

When both bands exist, lower- and upper-band endpoint slopes are reported similarly.

Gradients are edge-local diagnostics only. They are never computed through unsupported cells and are not promoted to a global derivative field.

## Determinism

- family order is the source report's declared `families` order;
- composition keys are deterministic fixed-precision strings;
- undirected edges are oriented by deterministic composition-key order;
- connected components are sorted by smallest member key;
- all output arrays are deterministically ordered.

## Reference v0.2.11 Geometry

The canonical two-family v0.2.11 surface contains, per subject:

```text
5 crosses-zero supported cells
1 positive-band supported cell
3 unsupported cells
```

Expected high-level geometry:

- one supported connected component of size 6;
- one crosses-zero component of size 5;
- one positive-band component of size 1;
- one supported↔unsupported boundary edge;
- one crosses-zero↔positive-band sign boundary edge;
- one positive-stability zero-crossing estimate;
- no negative-stability boundary.

## Error Handling

Reject:

- wrong source/schema/method version;
- duplicate mixture compositions;
- weights that do not match the declared family set;
- non-finite or out-of-range weights;
- weights that do not sum to one within tolerance;
- invalid grid step or tolerance;
- supported cells without finite point estimate and band payload needed for geometry.

Unsupported cells may legitimately omit resampling bands.
