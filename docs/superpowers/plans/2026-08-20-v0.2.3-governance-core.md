# CTCL-ITR v0.2.3 Governance Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Implement ApprovalRequest, DecisionReceipt, AuthorityGrant, deterministic ApprovalQueue semantics, resume eligibility, schemas, reference examples, CLI, and release validation.

**Architecture:** Keep canonical ATL TemporalEvent unchanged. Governance state lives in independent typed JSON objects and a dependency-free Python reference module; ATL events only reference governance IDs. The queue is in-memory and deterministic for semantic testing.

**Tech Stack:** Python 3.11+, standard library, JSON Schema Draft 2020-12, pytest.

**Spec:** `docs/superpowers/specs/2026-08-20-v0.2.3-governance-core-design.md`

## Global Constraints

- Do not change TemporalEvent required fields or meanings.
- Do not treat approval as equivalent to authority.
- Every resume eligibility decision must return structured reasons.
- Expired, denied, cancelled, deferred, revoked, exhausted, target-mismatched, or scope-mismatched grants must block resume.
- TDD: each behavior begins with a failing test.
